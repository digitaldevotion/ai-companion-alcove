## manageAnchor (add, update, or remove memory anchors)

Save an important global anchored memory that must be remembered in future sessions

**Syntax Example:**

<manageAnchor action="add">
Pippin's birthday is October 16th
</manageAnchor>
<manageAnchor action="update" id="50">
Pippin's birthday is October 16th. 
This year she's getting a ball for her birthday.
</manageAnchor>
<manageAnchor action="remove" id="50">
</manageAnchor>


**Notes:**
- YOU MUST USE THIS COMMAND IN ORDER TO PROPERLY SAVE, UPDATE, OR DELETE ANCHORS / MEMORIES
- Review context periodically for important memories to save
- You should only pick memories that are useful or important to save for future reference, for example:
  - important dates / times
  - life events (births, deaths, new jobs, new schools, etc.), new revelations, changes in life/relationship status
  - An inside joke
- Keep memories under 256 characters if possible, unless absolutely critical. These take up context memory so use sparingly!
- DO NOT SAY YOU'VE SAVED / UPDATED A MEMORY/ANCHOR IF YOU HAVE NOT CALLED THE TOOL!
- DO NOT SAVE A SIMILAR MEMORY/ANCHOR TO ONE YOU ALREADY HAVE. INSTEAD USE THE UPDATE ACTION TO UPDATE THE EXISTING MEMORY.
- LOOK FOR OPPORTUNITIES TO CONSOLIDATE MEMORIES WHEN POSSIBLE (UPDATE A MEMORY TO MERGE CONTENTS, THEN DELETE THE UNNECCESSARY ONES)
